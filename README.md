# 算数・数学 やさしくトレーニング

小学校の算数(6段階)から中学校の数学(3段階)までを、4択クイズと解説で学び直せる学習アプリです。
インストール不要・登録不要・完全オフライン対応(PWA)。

**▶ アプリを開く: https://maimmaim20230728-blip.github.io/math_training_web/**

## 収録内容(全問に解説つき)

- **小学校の算数**: 小学1年〜6年の6段階
- **中学校の数学**: 中学1年〜3年の3段階

各段階は学習指導要領の内容にそって単元に分かれています。
好きな段階の、好きな単元から始められます。

## 機能

- **単元練習**: 段階と単元を選んで1問ずつ。答えるとすぐに解説が読めます
- **10問チャレンジ**: 段階を選ぶと10問を通しで出題。最後にまとめて採点し、ベストスコアを記録します
- **弱点復習**: 間違えた問題だけをくり返し出題
- **解説閲覧**: 問題を選んで解説だけを読むこともできます
- **ふりがなの切替**: 小学校の範囲は漢字にふりがなが付きます(ホーム画面で消せます)
- 選択肢は毎回並び替わるので、位置で覚えてしまうことがありません
- 夜間モード(暗い配色)に対応。端末の設定にも自動で合わせます
- 学習記録は端末内(localStorage)にのみ保存され、外部に送信されません

## 内容について

- 問題と解説は、**すべて当団体が独自に作成したもの**です。
  学習指導要領(文部科学省告示)の各学年の内容にそって作成しており、教科書・市販ドリル・他アプリからの転載はありません。
- 学校・教科書会社・検定団体とは関係のない、非公式の学習ツールです。内容は開発元の責任によるものです。
- 正確性には多段の検証(独立検算・審査・機械検査)を行っていますが、誤りを見つけた場合はIssueでお知らせください。
